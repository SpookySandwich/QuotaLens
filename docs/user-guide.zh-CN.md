# QuotaLens 使用指南

## 安装与开始使用

从最新的 [QuotaLens Release](https://github.com/SpookySandwich/QuotaLens/releases/latest) 下载用户级安装程序或便携版压缩包。QuotaLens 需要 Windows 11 x64；发布包为自包含版本，无需另装 .NET 或 Windows App SDK。

启动后：

1. 选择 **添加平台**。
2. 选择服务商，并在统一配置页中完成连接。
3. 等待 QuotaLens 验证实时额度数据，再选择 **完成**。
4. 根据面板顶部的推荐，选择仍有足够可用额度的工具。

## 阅读面板

- **Recommended**：优先选择仍有余量的高价值有效套餐；按量付费余额只作为兜底容量。
- **有效可用量**：比较各套餐在未来 5 小时内能提供多少 token，与下方的排序方式无关。每 5 小时重置的套餐只计入当前窗口的剩余额度；按周或按月的套餐则计入全部剩余额度，因为没有任何限制会阻止你在一天内用完。方括号按重置频率将各区段分组，按量计费的 API 余额会按估算的混合单价折算为 token。
- **服务商卡片**：显示额度周期、重置倒计时、余额、账号明细以及警告或恢复操作。
- **隐私模式**：共享屏幕时遮蔽邮箱和余额。
- **排序**：可按套餐价值、重置频率或下次重置时间排序。
- **启动**：当所选数据源的可执行文件或网址可解析时，打开该数据源对应的工具。

服务商返回有效套餐信息时，卡片标题会附带套餐名；没有有效信息、套餐未启用或已过期时不会猜测套餐。

## 添加或编辑服务商

所有服务商使用同一张配置页，只显示该服务商真正支持的字段与操作。

存在多个数据源时，统一使用三种选择：

- **App**：读取已安装桌面应用的登录态或本机额度服务。
- **CLI**：读取服务商 CLI 的现有登录态；安全时可由 CLI 自己续期 token。
- **Web**：使用已保存的浏览器会话，或在配置页填写远程/API 凭据。

用户明确选择数据源后，QuotaLens 会严格使用它；出错时不会静默读取另一个账号。未明确选择时，QuotaLens 可以使用第一个已就绪的数据源。

可执行文件字段通常只是可选覆盖项。留空会使用界面显示的默认值并自动检测；手动填写的路径必须真实存在。路径下方的连接辅助按钮会使用当前尚未保存的路径，因此修改可执行文件后，**登录**或**打开应用**也会随之改变目标。

部分连接必须先返回真实数据，**完成**才会启用。应用或登录流程启动期间，配置页会显示进度并轮询所选数据源。选择 **完成**时还会执行最后一次实时拉取；失败会保留配置页并显示错误。

## 服务商说明

### Gemini

Gemini 的 **App** 同时支持 Antigravity 与 Antigravity IDE，因为两者暴露同一种本机额度服务。应用路径留空即可自动检测任一安装；App 数据就绪前，本机服务必须正在运行。

启用 **自动在后台启动 Antigravity** 后，如果服务不可用，QuotaLens 会在刷新前启动所选应用并等待数据。Gemini **CLI** 仍是独立数据源；它的启动操作会在终端中打开已配置的 CLI。

### Kimi

Kimi 的 **App** 复用桌面应用的短期登录态。Kimi 只在应用实际使用时续期；QuotaLens 不会改写或轮换属于 Kimi 的凭据。

若用户明确选择的 App 数据源失效，请使用 **打开应用**，并等待 Kimi 完成续期。之后 QuotaLens 会通过会话文件监视自动刷新额度与套餐信息。使用自动数据源选择时，App 不可用期间可以改用其他已就绪的 Kimi 数据源。

### Grok

Grok 复用已有的 Grok CLI 登录态。如果卡片提示需要登录，请使用已配置的可执行文件运行 `grok login`，然后刷新服务商。

## 故障排查

### “完成”不可用

- 补全必填字段，并修正标为 **文件不存在** 的路径。
- 若数据源需要验证，请使用对应的 **登录**或**打开应用**按钮，并等待实时数据。
- 修改已经验证过的可执行文件路径后，需要重新验证。

### 卡片没有套餐名

只有所选数据源返回有效套餐身份时，QuotaLens 才会显示套餐。请在应用、CLI 或浏览器会话续期后刷新服务商。某些服务商能返回有效额度却不提供订阅元数据，此时卡片可以正常显示用量而不附带套餐名。

### 没有启动按钮

只有所选数据源能解析出可执行文件或网址时，启动操作才会出现。请检查数据源选择和对应路径。可选路径留空会自动检测；手动填写的路径必须指向现有文件。

### App 数据过期或不可用

打开已配置应用并刷新。有些本机服务只在应用运行时存在，也有些应用只有在变为活动状态后才会续期凭据。

## 隐私与本地数据

QuotaLens 没有 QuotaLens 后端、账号或遥测，只会访问用户主动配置的服务商。

配置和最近一次健康快照保存在 `%LOCALAPPDATA%\QuotaLens`。在配置页输入的 API Key 以明文 JSON 保存，依靠 Windows 用户账号的文件权限保护，不会额外加密。内嵌浏览器会话使用本机 WebView2 配置文件。QuotaLens 会读取服务商自己的 CLI 或应用凭据，但不会改写它们。

如果某个 API Key 不适合以这种方式保存在本机，请改用能够复用现有应用、CLI 或浏览器登录态的数据源。
